# v1.10.38-lts

## 修复与优化

本版本为 2026-08-27 全库安全审查的修复发布，共 12 项，全部经端到端验证：

- **修复解压/压缩命令注入（关键）**：zip/tar/tar.gz 解压与压缩改为加固 SDK 路径优先，shell 归档器降级为兜底且所有路径/密码经字符校验（原可经恶意文件名/密码以 root 执行任意命令）
- **修复回收站还原绕过保护**：还原操作补齐受保护目录检查与字符校验（原可构造条目名删除并覆盖 `/etc/passwd` 等任意受保护文件）
- **修复剪切/复制/移动命令注入**：`Mv`/`Cut`/`Copy` 系列全部路径校验（原经恶意文件名可 root 执行命令；`file_op.go` 审计后零残留）
- **修复网站名称类路径穿越**：反向代理/重定向名称、更新代理/重定向文件、网站别名、容器名统一校验（原可穿越 nginx include 目录以 root 写/删任意 `.conf`，别名与容器名可流入未加引号的 shell）；中文/空格/点横线名称完全兼容
- **修复 MFA 爆破绕过**：MFA 待验证阶段的 stage-1 登录不再重置限流计数（原知道密码即可无限重置后爆破 TOTP，5 次/30 分钟上限失效）
- **改密与密码过期处理走 RSA 信封**：不再明文传输与比较（`hmac.Equal` 常量时间），明文提交被拒绝；`1pctl` 改密路径不受影响
- **安装与升级完整性校验**：install.sh 与面板自升级接入 sha256 校验（校验和不匹配或缺失拒绝安装）；下载目录改为每次运行独立临时目录（消除本地符号链接/竞态提权）
- **面板稳定性**：定时任务链修复 `Recover` 真正生效（任务 panic 不再杀死面板进程）；计划任务串行守卫 + panic 兜底（慢任务不再自我重叠，手动触发运行中任务会被跳过并记日志）；镜像构建/拉取 use-after-close 修复；快照/备份大小加载的数据竞争修复
- **错误处理修复**：`errors.Is` 参数反序（被包裹的业务错误现在正确映射友好文案）；非法路径参数返回 400（不再以 id=0 继续执行）；11 处 `tx.Commit` 错误不再被忽略（避免"提示成功但数据未保存"的幻影状态）
