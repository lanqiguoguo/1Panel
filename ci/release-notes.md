# v1.10.42-lts

本版本包含第六轮全库安全审查的累计修复：5 项高危（RCE/注入类）、9 项重要问题与一批低危加固，覆盖命令注入、路径穿越、SSRF、鉴权边界、凭据显示等。**普通用户（面板直连、无 API 自动化）升级无感；有 API 自动化或使用 MCP/AI 域名绑定功能的用户请阅读文末「升级注意事项」。**

## 安全加固（高危）

- **修复 ClamAV 扫描规则注入**：扫描任务名称/目录在创建与更新入口统一白名单校验，执行与删除前再校验，阻止经规则名在主机以 root 执行任意命令、任意目录删除与越权读取扫描日志
- **修复计划任务更新类型混淆**：更新接口按数据库中实际任务类型校验参数，URL 在入口与执行双重校验，阻止借"声明类型"绕过校验向 curl 任务注入命令
- **修复网站更新域名注入**：更新站点主域名与创建同等校验域名格式，日志切割 tar 命令参数加引号，阻止经主域名注入命令或穿越读写 nginx 配置
- **修复文件创建绕过保护路径**：新建文件/目录/链接与删除、改名同等拦截保护路径；创建时剥离 setuid/setgid 等特权位，不再能借文件管理器在系统目录放置 SUID 文件
- **修复远程数据库命令注入**：远程 MySQL/PostgreSQL 备份恢复的地址、用户名、库名、字符集全部白名单校验；从远程服务器同步的库名入库前过滤，被攻陷的远程数据库无法借备份任务在面板主机执行命令

## 安全加固（重要）

- **PostgreSQL 远程备份口令移出进程命令行**：改经 0600 环境文件传递，宿主机进程列表不再可见（MySQL/Redis 此前已完成）
- **修复应用备份文件名穿越**：自定义备份文件名强制为安全归档名，删除备份记录前复核存量路径，阻止任意目录写入与级联删除
- **修复分片上传与远程下载绕过保护路径**：分片合并、wget 下载目标与普通上传同等拦截保护目录，下载文件名拒绝路径分隔符
- **MCP/AI 绑定域名强制 IP 白名单**：MCP Server 与 Ollama 反代均无内建认证，绑定域名时必须配置允许访问的 IP 或 IP 段，不再默认暴露到公网
- **修复上传证书 SAN 注入**：手动上传证书的域名逐个校验格式，下载证书前复核存量记录，阻止经证书域名穿越写文件
- **前端业务路由全面纳入会话守卫**：54 处业务页面路由补齐鉴权标记，未登录直接访问 URL 由路由守卫拦截（后端 API 鉴权不受影响）
- **镜像仓库登出与升级拷贝参数化**：docker logout 与应用升级文件拷贝改为参数化执行并校验存量数据，历史遗留的恶意记录不再能借编辑/删除触发命令执行
- **修复远程下载 SSRF**：每次连接与每跳重定向均复验目标地址公网性，DNS 重绑定与重定向跳转无法再探测内网或云元数据
- **文件剪切安全加固**：剪切改为原子系统调用并在执行点复核保护路径，跨设备移动自动回退
- **凭据显示默认掩码**：已安装应用密码参数、远程数据库连接信息抽屉默认掩码，点击才显示

## 低危加固

- **JWT 签名密钥缺失拒绝启动**：签名密钥行丢失时面板不再以空密钥降级启动
- **启用 MFA/修改安全入口吊销全部会话**：与修改密码行为一致，已存在的旧会话立即失效
- **安全入口格式校验收紧**：菜单设置接口与主设置接口同等校验入口格式
- **模型与 MCP 服务名称校验**：Ollama 模型名与 MCP 服务名拒绝穿越与元字符，日志与配置写入限定在面板目录内
- **hosts/resolv.conf 写入防注入**：主机名映射与 DNS 服务器条目拒绝换行与注释符
- **会话超时参数防自锁**：会话超时限定有效范围，非法值不再可能导致面板无法登录
- **前端隐私与外链卫生**：安全入口码不再写入浏览器本地存储并在登出清除；容器/Redis 日志连接参数统一编码；全部外跳链接隔离 opener

## 修复

- **文件剪切兼容跨设备移动**：剪切跨文件系统时自动回退系统 mv，同设备为原子操作
- **wget 下载路径**：目标校验前置，失败不再产生残留文件
- **镜像仓库连接检查与删除**：异常存量值处理不再中断主流程

## 升级注意事项

- **MCP/AI 域名绑定（重要）**：绑定域名现在必须填写 IP 白名单（支持 IP 段）。已绑定但未配置白名单的域名在更新时会要求补填；动态地址用户可配置运营商网段级白名单
- **API 自动化脚本**：远程数据库地址/用户名新增字符白名单（字母数字与 `._-:` 等），含特殊字符的存量连接更新时会被要求调整；应用备份自定义文件名仅接受 `.tar.gz` 后缀的安全文件名
- **文件管理器**：新建文件/目录/链接现在与删除、改名一样受保护路径限制；创建文件不再接受 setuid 等特殊权限位
- **前端**：业务页面路由改为需要登录会话，未登录直接访问业务 URL 会跳转入口页（正常浏览器流程无感知）
- `ApiKeyValidityTime=0`（不做时间戳校验）的文档化行为保持不变
