# v1.10.39-lts

## 新功能

- **面板代理生效范围对齐上游 V2**：
  - **Docker 拉取镜像走代理**：代理设置新增"同步到 Docker"开关，可将面板代理写入 Docker daemon 配置（daemon.json `proxies`）并自动重启 Docker 生效；写入前自动备份、配置经 dockerd 校验、重启后探测存活，任一环节失败自动回滚并明确报错；启用前确认框警示容器将短暂停止（建议先开启 live-restore）
  - **申请证书走代理**：ACME 账户注册、证书订单与 ZeroSSL EAB 获取全部经面板代理出站；超时参数对齐 lego 官方默认（2 分钟），修复原传输层 10 秒响应头超时对 CA finalize 偏紧的问题
  - 代理设置说明文案更新为实际生效场景（应用商店 / 版本升级 / 申请证书 / Docker）

## 修复

- **修复应用安装失败时不显示任何错误**：安装失败原因（如镜像拉取网络错误）现在写入应用状态并在面板日志记录——此前安装失败仅显示状态、消息为空且日志无任何痕迹
- **修复代理密码"留空保持原密码"不生效**：勾选"记住密码"后留空保存不再清空已存密码（未勾选时留空仍会清除密码）
